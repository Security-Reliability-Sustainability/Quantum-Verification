Notes
-----
- qutip 5.2.3 was built from source (no aarch64 wheel) and installed editable.
- Original paper requirements pinned: numpy>=1.24, scipy>=1.10, pandas>=2.0,
  matplotlib>=3.7, PyYAML>=6.0, qutip>=5.0, qutip-qip>=0.4, qiskit>=1.0, mqt.bench>=1.1.
  Installed versions satisfy all lower bounds. qiskit resolved to 2.x and
  mqt.bench to 2.2.2 (newer than the >=1.1 pin); the get_benchmark /
  BenchmarkLevel.ALG API used by workload_replay.py is unchanged and all
  Section-3 numbers reproduce (see VERIFY.md), so the version drift is benign.
- qutip-qip is listed in requirements.txt but is NOT imported by any module in
  the audited pipeline, so it was not required to reproduce results.
